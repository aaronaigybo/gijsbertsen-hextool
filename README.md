# Gijsbertsen-hextool

Een open-source AI-tool voor BMW ECU bin-file bewerking.

## Functionaliteiten
- AI-gestuurde analyse van bin-files
- Ondersteuning voor DME, DSC, DTC
- Automatische detectie van ECU-types en firmwareversies
- Hexadecimale editor met patroonherkenning
- Specifieke aanpassingen (EGR, OPF, DPF uitschakelen)
- VIN (chassisnummer) aanpassing en validatie
- Virginizen van ECU's
- Compatibiliteit met Autotuner en Microtronics
- Automatische checksum berekening en correctie

## Installatie

1. Clone de repository:
```bash
git clone https://github.com/aaronaigybo
/gijsbertsen-hextool.git
cd gijsbertsen-hextool
```

2. Installeer de vereisten:
```bash
pip install -r requirements.txt
```

3. Start de applicatie:
```bash
python src/main.py
```
